# 基于FreeRTOS的STM32直流电机双闭环伺服控制系统
## 项目简介
基于STM32F103 + FreeRTOS实现直流电机位置‑速度双闭环PID伺服控制，完成电机调速、位置定位，支持串口指令控制，OLED实时显示运行状态。

## 硬件平台
- 主控：STM32F103单片机
- 外设：直流电机、正交编码器、OLED显示屏

## 开发环境
- IDE：Keil MDK‑5
- RTOS：FreeRTOS

## 主要实现功能
1. FreeRTOS多任务开发，电机控制任务配置为最高优先级，保障运动控制实时性。
2. 定时器正交解码读取编码器反馈，实现**位置‑速度双闭环PID控制**，整定参数抑制超调，减小位置稳态误差。
3. FreeRTOS消息队列实现多任务之间数据交互。
4. 支持串口下发指令控制电机，OLED屏幕实时显示电机转速、位置工况。

## 调试遇到的问题与解决
1. 任务栈分配不足，发生栈溢出 → 调大对应任务栈深度，解决系统崩溃。
2. 多任务抢占导致电机运行扰动 → 优化任务优先级划分，临界区保护共享数据。

## 使用说明
1. 使用Keil5打开工程文件 `MotorServo.uvprojx`
2. 根据实际硬件修改引脚宏定义参数
3. 编译下载至STM32F103开发板运行
